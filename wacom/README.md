# wacom

What the Wacom "1000 Hz" firmware mods change, looked at on 2026-10-06 for section 6.3 of the
main README. No firmware files are included, only diffs, hashes and page snapshots.

* `ctc4110_459hz_vs_official_1.07_diff.txt`: the 30 bytes that differ between the CTC-4110
  459 Hz mod and the official 1.07 firmware.
* `lc87_pairs_diff_sizes.txt`: diff sizes for the LC87 (CTL-472 family) pairs, not analysed further.
* `hashes_of_files_analysed.txt`: hashes of every file compared.
* `tabletvit_page_strings_2026-10-06.txt`, `xstarry_firmware_catalog_snapshot_2026-10-06.json`:
  what the two download pages said on that day.
